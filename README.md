# Beans editor support

Editor integrations and shared language assets for the
[Beans programming language](https://github.com/beans-lang/beans).

The `icons/` directory contains light and dark file icons for `.b` source files
and the exact `beans.pot` module manifest name. Editor extensions and language
server clients belong in editor-specific directories as they are added.

Beans language intelligence is provided by `beansc lsp` from the main
repository.
